Machine Learning Based Content Decline Detection for Search Refresh Prioritization

FlyRank ML Internship Capstone

Abstract

This study investigates whether machine learning can identify content pages associated with declining performance and help prioritize pages for search-content review. Using the public FlyRank internship starter dataset, the study compares Logistic Regression and Random Forest models after removing identifier and leakage-risk product flag features. The models classify pages using the is_declining label and generate an opportunity score that is used to rank pages for potential refresh review. On the held-out test set, Logistic Regression achieved 92.87% accuracy and an F1 score of 0.8320, while Random Forest achieved 87.63% accuracy and an F1 score of 0.7448. Both models achieved Precision@50 of 1.00 compared with 0.04 for the custom lowest-CTR baseline, showing strong ranking performance on this test split.

1. Introduction / Problem Statement

Content performance changes over time, and organizations need practical ways to identify pages that may require review or updating. Manually reviewing a large collection of pages can be inefficient.

This project investigates the following research question:

Can historical search and content-performance signals be used to identify pages associated with content decline and prioritize them for refresh review?

The goal is not to claim that refreshing a page will necessarily improve its future performance. Instead, the model provides a data-driven prioritization mechanism for identifying pages that warrant further human review.

2. Data

The experiment uses the anonymized FlyRank internship starter dataset containing content-performance records.

Important features used in the analysis include:

  • Search volume
  • Competition
  • Content type
  • Main intent
  • Word count
  • Content age
  • Impressions
  • Clicks
  • Sessions
  • CTR
  • Average position
  • Engagement-related measurements

The target variable was is_declining.

Identifier columns such as content_id and client_id were excluded from modeling. Product-generated flags such as health_score, is_quick_win, is_underperformer, needs_ctr_fix, and is_initial_refresh_candidate were also excluded because they may introduce label leakage.

3. Methodology

The dataset was divided into 80% training data and 20% testing data using a stratified split with a random seed of 42.

Logistic Regression

Logistic Regression was used as a relatively simple classification model for predicting whether a content record belonged to the declining class.

Random Forest

Random Forest was used to capture nonlinear relationships between content-performance features and the decline label.

Numerical features were median-imputed and standardized. Categorical features were imputed using the most frequent value and one-hot encoded.

The predicted probability of decline was used as the opportunity score. Pages were sorted by this score to create a ranked list.

The primary ranking metric was Precision@50:

Precision@50 = declining pages among the top 50 ranked pages / 50

A simple baseline was also created by ranking pages according to lowest CTR.

The custom lowest-CTR baseline identified 2 declining pages within its top 50, resulting in Precision@50 of 0.04.

Both machine-learning models identified 50 declining pages among their respective top 50 predictions on this held-out test split.

The Random Forest feature-importance analysis identified historical impression volume, click activity, CTR, session activity, and content age among the influential predictive features.

These feature-importance results represent predictive associations and should not be interpreted as causal relationships.

6. Feature Importance

The Random Forest model highlighted several historical performance variables as influential predictors. The most prominent features included previous 30-day impressions, 90-day impressions, last 30-day impressions, days with impressions, impression tier, CTR, clicks, sessions, pageviews, and content age.

The feature importance analysis is intended to improve interpretation of the model and does not establish that changing any individual feature would cause content performance to improve.

7. Limitations

  • The evaluation is based on a single train-test split of the FlyRank internship starter dataset.
  • The target variable represents observed content decline and does not measure whether a subsequent refresh would improve performance.
  • The high Precision@50 observed on this split may not generalize to unseen datasets or future time periods.
  • Temporal validation would provide a stronger test of real-world deployment performance.
  • Feature importance indicates predictive association rather than causation.

8. Reproducibility

The experiment was implemented in Python using pandas, NumPy, scikit-learn, and Matplotlib.

A fixed random seed of 42 was used for the train-test split and model training. The preprocessing pipeline, classification models, evaluation metrics, ranking procedure, and recommendation generation are contained in the accompanying notebook.

9. Conclusion

This study demonstrates a machine-learning approach for prioritizing content associated with performance decline. Logistic Regression achieved 92.87% accuracy and an F1 score of 0.8320, while Random Forest achieved 87.63% accuracy and an F1 score of 0.7448. Both models achieved Precision@50 of 1.00 on the evaluated test split, compared with 0.04 for the custom lowest-CTR baseline.

The resulting opportunity score can therefore be used as a prioritization signal for human review. Further evaluation using temporal validation and future-period data would be necessary before treating the approach as a production decision system.
